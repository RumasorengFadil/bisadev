# Bisadev

Situs agensi digital Bisadev dibangun dengan Next.js App Router. Repository ini berisi halaman publik untuk layanan, portofolio, artikel, dan kontak; halaman autentikasi; dashboard pengelolaan blog/kategori; serta route chat streaming. Data blog, kategori, dan akun berasal dari backend HTTP eksternal.

## Menjalankan secara lokal

Gunakan `npm ci`, siapkan `.env.local` sesuai lingkungan kerja, lalu jalankan `npm run dev`. Buka `http://localhost:3000`.

Daftar variabel yang dibaca aplikasi, batasan setup, dan proses build ada di [panduan instalasi](docs/deployment/installation.md). Mulai dari [indeks dokumentasi](docs/README.md) untuk arsitektur, alur fitur, konvensi dokumentasi, dan riwayat perubahan.
